# COMP 484 Homework 2

This project was part of the COMP 484 reference site homework 2. The assignment focused on working on a similar website to the one of the first homework, but focused on creating and applying a semantic structuring strategy across the HTML pages.

The work mainly included analyzing the structure of `structure.html`, creating a document outline, and then adding semantic HTML elements in the other default html files in order for them to match the same structuring strategy shown in the `structure.html` file, by adding elements such as `header`, `nav`, `main`, `article`, `section`, `aside`, and `footer`, and adding ARIA roles.
